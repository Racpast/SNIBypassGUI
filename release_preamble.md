**Install / 安装**

Download the ZIP below, extract the **whole** archive to a fixed folder, then run `SNIBypassGUI.exe` from there. Do not run it from inside the archive.

下载下方 ZIP，将**整个压缩包**解压到一个固定文件夹，再从该文件夹运行 `SNIBypassGUI.exe`。请勿直接在压缩包内运行。
